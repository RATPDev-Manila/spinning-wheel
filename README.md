# Philippines Railway Summit 2026 Lucky Spin

This is a standalone static page deployed to Vercel from the repository root.

## Wheel setup

Select **Wheel Setup** on the kiosk to add, remove, or rename prizes and adjust their relative weights. A weight of `0` excludes a prize from the draw; equal positive weights give prizes equal chances.

Prize settings and spin entries are stored only in the browser on the kiosk device. Use **Export CSV** regularly to download entries for Excel. The app does not sync data to the cloud. Anyone using the kiosk can open Wheel Setup, so keep the kiosk supervised and protect downloaded attendee data.

## Deploy

Push changes to the connected GitHub branch. Vercel automatically deploys the root `index.html` as a static site; no build or install command is required.
